# 🎬 Netflix Landing Page

A simple and visually appealing **Netflix-inspired landing page** built using **HTML5** and **CSS3**. This project was created as part of a Full Stack Web Development practice session to improve frontend development skills and understand webpage layout, styling, and animations.

---

## ✨ Features

- 🎨 Netflix-inspired user interface
- 🌈 Attractive gradient background
- 🖼️ Featured Netflix banner
- 🎬 Movie cards with posters
- ✨ Smooth hover animation effects
- 📱 Clean and user-friendly design
- 💻 Developed using only HTML and CSS

---

## 🛠️ Technologies Used

- HTML5
- CSS3
